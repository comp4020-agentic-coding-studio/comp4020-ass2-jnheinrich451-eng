# WORKSPACE

## Focus
It focus on a compilable platform with existing data, environment installed, let students to run the code to discover, explore, edit and learn.

## Settings
It is not **fixed**, the proposed design is it is an open coding platform, can refer jupyter notebook's design, with start, interrupt, restart, +markdown, +code, terminal operations. Yet, the changes can be made as the left part is coding, file manipulation, and right is the visualization, or compiled part. For each cell, normally the notebook presentation, the results will under each cell. And right part is a compiled interface. This compiled visualization part remain designing.

## Basic Functions
Users can normally read, write, run the codes with correct results. Can import more libraries. Can visualize the result.
